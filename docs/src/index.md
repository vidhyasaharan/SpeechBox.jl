# SpeechBox Documentation

*A speech processing toolbox for Julia*



## Outline
Currently SpeechBox.jl implements routines for 
- Speech Framing
- Voice Activity Detection
- Spectral Analyses
- LPC Analyses
- MFCC extraction
- Plot Recipes

SpeechBox.jl also defines [Data Structures] (@ref speech_objects) to hold the inputs and outputs to the speech processing routines
